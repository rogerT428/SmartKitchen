Dapur merupakan salah satu area rumah yang menggunakan gas untuk kebutuhan memasak.
namun, kebocoran gas dapat terjadi tanpa disadari dan berpotensi menimbulkan bahaya bagi penghuni rumah. Oleh karena itu,
diperlukan teknologi yang dapat membantu memantau kondisi gas dan memberikan informasi lebih awal mengenai potensi bahaya.
Smart Kitchen dikembangkan sebagai aplikasi berbasis Android dan Internet of Things (IoT) dengan memanfaatkan sensor MQ-2
dan mikrokontroler ESP32 untuk mendukung pemantauan kondisi gas di dapur.
Aplikasi ini dirancang untuk menampilkan informasi pemantauan, memberikan peringatan ketika terindikasi kondisi berbahaya, serta menyediakan panduan tindakan darurat.
Melalui Smart Kitchen, diharapkan pengguna dapat lebih waspada terhadap potensi kebocoran gas,
mengenali risiko lebih cepat, dan meningkatkan keselamatan serta kenyamanan saat beraktivitas di dapur.

Fitur Utama :
- Login dan Register pengguna
- Dashboard pemantauan gas
- Monitoring dan riwayat pembacaan sensor
- Notifikasi peringatan kondisi gas
- Panduan darurat kebocoran gas
- Pengaturan dan informasi aplikasi
